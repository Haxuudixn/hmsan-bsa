# Gated Hierarchical Memory Sparse Attention Network for Multi-Modal Tender Document Slice Classification

## Abstract

Tender document slice classification is a critical yet under-explored task in document intelligence, facing challenges in multi-modal heterogeneity, long-range cross-page context modeling, and chapter boundary detection. This paper proposes HMSAN-BSA (Hierarchical Memory Sparse Attention Network with Boundary-aware Section Aggregation), an end-to-end architecture that integrates four key components: (1) a three-branch multi-modal encoder using RoBERTa-wwm-ext, ViT-B/16, and OCR-enhanced dual-path fusion for text, image, and mixed-type slices; (2) a Gated Sparse Attention (GSA) page encoder that replaces fixed local-window sparsity with a learnable gated lightning indexer and adaptive sparsity controller; (3) an Infini-attention compressive memory mechanism maintaining O(d^2) constant-space cross-page context with boundary-gated section memory; and (4) a comprehensive eight-position gated attention framework spanning fusion, value modulation, indexer scoring, output gating, cross-page interaction, feed-forward layers, memory readout, and boundary-aware updates. The model contains only 2.5M trainable parameters while leveraging frozen pre-trained encoders, making it suitable for small-sample tender document scenarios. We further conduct a systematic literature survey confirming that the proposed architecture aligns with state-of-the-art developments in sparse-gated attention (2024-2026). An ablation study design is presented to isolate the contribution of each gating position and the compressive memory mechanism.

**Keywords**: tender document classification; multi-modal document understanding; gated sparse attention; Infini-attention; hierarchical memory network; boundary detection
