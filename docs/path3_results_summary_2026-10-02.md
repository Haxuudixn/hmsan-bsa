## 0. 一句话结论

主模型在留出测试集上是 **0.9321 准确率 / 0.8672 macro F1**，对最强基线 B3（匹配分母）领先 **+12.09 pp 准确率 / +5.38 pp macro F1**。

验证集上主模型相对 B3 是 macro F1 **落后 0.59 pp**，测试集上变成 **领先 5.38 pp**——工作稿 §5.1 里那条需要靠"数据主体更强"来圆的表述，在测试集口径下不再需要。

## 7. 与工作稿的主要差异

1. **A6（移除跨页记忆）在测试集上反转。** 验证集 macro F1 0.8715 高于主模型 0.8546，工作稿据此写了"跨页记忆压低长尾"（§5.2 / §6.5）；测试集上 A6 是 0.7779，落后主模型 8.93 pp，`<100` 档从 0.6587 崩到 0.2679。该叙事应撤掉，改为"跨页记忆主要保住小支持度类"。
2. **多数消融在测试集上从灰色区变成可分辨。** A2 −2.22→−4.96、A7 −2.80→−6.87、A11 −4.72→−14.42（pp），工作稿"只有 A11 稳健"的结论可以放宽为"五个消融行中四个可分辨"。
3. **B3 的 macro F1 优势消失。** 验证集 −0.59 pp → 测试集 +5.38 pp（主模型领先）。
4. **A10（=B4 全连接融合）在测试集上 +0.91 pp**，仍在噪声底之内，维持"平手"的表述。
